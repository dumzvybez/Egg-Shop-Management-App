## ✨ Overview

EggShop is a simple business management application designed for small family egg shops.

It helps owners manage:

- 🥚 Daily egg sales
- 📦 Inventory
- 🚚 Suppliers
- 👥 Customer credit
- 💰 Profit
- 📊 Reports
- 🧾 Expenses

Everything works completely **offline**, making it perfect for everyday shop use.

---

# 🚀 Features

| Module | Description |
|---------|-------------|
| 🥚 Daily Sales | Daily prices, sales calculation and profit tracking |
| 📦 Inventory | Live stock management with automatic updates |
| 🚚 Suppliers | Supplier records, purchases and partial payments |
| 👥 Customer Credit | Track customers who pay later |
| 💰 Profit | Daily, monthly and yearly profit reports |
| 🧾 Expenses | Track additional business expenses |
| 📊 Reports | Interactive charts and PDF reports |
| 🌙 Themes | Dark & Light mode |
| 🌐 Languages | Sinhala & English |
| 📱 PWA | Installable, fully offline |

# 📱 Main Features

### 🥚 Daily Business
- Daily price management
- Multiple price sessions
- Damage egg tracking
- Daily profit calculation
- Edit & recalculate records

### 📦 Inventory
- Live stock updates
- Stock movement history
- Low stock warnings
- Automatic inventory deduction after sales

### 🚚 Supplier Management
- Supplier profiles
- Purchase history
- Multiple egg types per purchase
- Partial payment tracking
- Outstanding balances

### 👥 Customer Credit
- Customer records
- Credit tracking
- Partial payments
- Payment history

### 💰 Reports
- Daily reports
- Monthly reports
- Charts
- PDF export
- Search & filtering

# 📦 Installation

```bash
git clone https://github.com/dumzvybez/Egg-shop-management-app.git

cd Egg-shop-management-app

npm install

npm run dev
```

Open:

```
http://localhost:3000
```

# 📱 Progressive Web App
